# Stock Statistical Analysis

First project of my quantitative finance roadmap.

## Objective

The goal of this project is to analyze historical stock market data using Python.

We will study:

- stock prices
- daily returns
- volatility
- drawdowns
- return distributions
- financial visualizations

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
